# College Information Chatbot

A Python-based chatbot that provides information about a college, including courses, admissions, placements, facilities, faculty, and contact details.

## Features

- College Information
- Course Details
- Admission Process
- Placement Information
- Faculty Information
- Hostel Information
- Library Information
- Scholarship Information
- Contact Details
- User-Friendly Interface
- Exit Option

## Technologies Used

- Python
- VS Code

## Concepts Used

- Variables
- Input and Output
- Conditional Statements (if-elif-else)
- While Loop
- Lists
- String Handling

## How to Run

1. Install Python 3.x
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python chatbot.py
```

## Sample Output

```text
Welcome to College Information Chatbot

You: college
Bot: College Name is Zeal Education Society.

You: courses
Bot: We offer courses in CS, IT, AIML and many more.

You: bye
Bot: Thank You!
```
