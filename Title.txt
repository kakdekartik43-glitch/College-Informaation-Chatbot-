                              Title
...College Information Chatbot Using Python……



*  Objective
The main objective of this project is to develop a chatbot that provides information about a college such as courses, admission process, facilities, placements, contact details, and other student-related queries.


* Introduction
This project is a rule-based chatbot developed using Python. It interacts with users and provides predefined responses to college-related questions.


*  Software Requirements
* Python 3.x 
* VS Code / IDLE 
* Windows Operating System


*  Features
* College Information 
* Course Details 
* Admission Process 
* Placement Information 
* Faculty Information 
* Hostel Information 
* Library Information 
* Scholarship Information 
* Contact Details 
* Exit Option






*  Algorithm
Step 1: Start the program.

Step 2: Display "Welcome to College Information Chatbot".

Step 3: Initialize a counter variable count = 0.

Step 4: Start an infinite loop using while True.

Step 5: Increment the counter by 1.

Step 6: Accept user input and convert it to lowercase.

Step 7: Compare the user input with predefined keywords.

Step 8: If the input matches a valid query, display the corresponding college information.

Step 9: If the input matches an exit command (bye, exit, quit, etc.), display a thank you message and terminate the loop.

Step 10: If the input does not match any predefined query, display "Sorry, I don't understand."

Step 11: Repeat Steps 5 to 10 until the user exits.

Step 12: Display the total number of questions asked.
Step 13: End the program.
